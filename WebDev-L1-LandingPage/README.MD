
# 🎧 boAt Landing Page
A modern, responsive, and visually appealing landing page
inspired by boAt, an Indian lifestyle and audio brand.
This project showcases a collection of audio products
including wireless earbuds, headphones, smartwatches,
and Bluetooth speakers.
The website is built using HTML5 and CSS3 with a focus
on clean design, responsive layouts, and user experience.
## 📸 Project Preview
A modern landing page featuring:
- Premium dark hero section
- boAt-inspired red and black color palette
- Featured product collection
- About boAt section
- Product features section
- Call-to-action section
- Responsive footer
---
## 🚀 Features
- Sticky navigation bar
- Responsive design for desktop, tablet, and mobile
- Modern hero section with CTA buttons
- Product cards with images and prices
- Product hover animations
- About section
- Features section
- Footer with social media links
- Smooth scrolling navigation
- CSS Grid and Flexbox layouts
- Clean and readable typography
---
## 🛠️ Technologies Used
- HTML5
- CSS3
- Google Fonts
- CSS Grid
- Flexbox
- Media Queries
No JavaScript is required for this project.

## 📱 Responsive Design
The website is designed to work across different screen sizes.
- Desktop: Three-column product layout
- Tablet: Two-column product layout
- Mobile: Single-column product layout
CSS media queries are used to ensure
the layout adapts to different devices.
