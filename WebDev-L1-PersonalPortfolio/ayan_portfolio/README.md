# Ayan's Personal Portfolio Website

A modern, responsive personal portfolio website built with **HTML5, CSS3, and vanilla JavaScript**. It showcases an introduction, about section, technical skills, project cards, and contact links.

## Features

- Responsive layout for desktop, tablet, and mobile
- Modern dark theme with blue and cyan gradient accents
- Google Fonts (Inter) for typography
- Hero section with profile avatar placeholder
- About Me section
- Technical skills grid
- Project cards with GitHub repository links
- Contact section with email, GitHub, and LinkedIn links
- Smooth scrolling between sections
- Interactive mobile navigation menu
- Automatically updated copyright year
- Reduced-motion accessibility support

## Built With

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or another editor.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a local preview.

## Deployment with GitHub Pages

1. Create a GitHub repository for your portfolio.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Select deployment from the `main` branch and the root folder (`/`), then save.
5. Wait for GitHub Pages to publish the site and open the URL it provides.
